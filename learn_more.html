Introduction — What is SYNOP?

SYNOP (FM-12) is the WMO’s standard numeric code for surface synoptic observations produced by land stations (staffed or automatic). It encodes time, station identifier, wind, visibility, present & past weather, cloud, temperature, pressure, precipitation and more in compact five-character groups that are unambiguous worldwide. The formal specification and code tables are maintained by WMO and published in the Manual on Codes. :contentReference[oaicite:0]{index=0}

This reference focuses on the typical Section 1 groups used by land stations and includes the practical WMO tables most frequently used when decoding SYNOP messages. For the complete registry of present-weather terms see WMO code table 4678. :contentReference[oaicite:1]{index=1}

General format (compact overview)

A SYNOP message is composed of numbered sections (0–5). The typical land station (standard SYNOP) message starts with the identification/time group followed by the main observation groups (Section 1) — each group is either five characters or an indicator plus four characters:

YY GG i_w  IIiii  iR ix  h  VV  N dd ff  1sTTT  2sTdTdTd  3PPPP  4PPPP  5appp  6RRRtR  7wwW1W2  8NhCLCMCH  9GGgg

Below we step through each of these groups, then provide the full, authoritative code tables used to decode them. Use the sidebar to jump to any code table.

Section-1: core groups explained (group-by-group)

YY GG i_w

YY = day of month (UTC). GG = hour of observation (UTC). i_w = wind/wind-unit indicator; it tells how wind speed is encoded and whether speed is in m/s or knots (and whether gusts are included for automatic sensors). See the Wind / i_w section for the i_w table. :contentReference[oaicite:2]{index=2}

IIiii

Station identifier (WMO block and station number).

iR, ix

Indicators that control inclusion of precipitation section (iR) and whether the station is staffed / automatic and whether past weather groups are included (ix). Automatic stations can omit some groups (e.g. past weather) — see the Automatic vs Manned section. :contentReference[oaicite:3]{index=3}

h

Cloud base of lowest cloud seen (coded — table provided below). Use code table 1600/modified tables; 0 = 0–50 m, 1 = 50–100 m, 2 = 100–200 m, etc., 9 = >2500 m / unknown. Source: WMO SYNOP documentation. :contentReference[oaicite:4]{index=4}

VV (visibility)

Horizontal visibility in coded form. Common practice: codes for 000-999 representing particular ranges or exact metre values; table below summarises the widely used mapping for land SYNOP. See the WMO tables for full precision. :contentReference[oaicite:5]{index=5}

N (cloud amount)

Amount of sky covered by cloud in oktas (0–8), using WMO code table 2700. The digit corresponds to the number of oktas; when no low cloud is present the amount of medium cloud is used in that position. See the Cloud Amount table below. :contentReference[oaicite:6]{index=6}

dd ff

Wind direction in tens of degrees (dd) and wind speed (ff) using units specified by i_w. "00" for calm direction. See Wind table. :contentReference[oaicite:7]{index=7}

Groups 1 & 2 — temperature and dew point

1sTTT — air temperature: sign (s) and three digits (TTT) in tenths °C (encode negatives with leading 1 or '9' depending on practice); 2sTdTdTd — dew point similarly. Table & examples below. :contentReference[oaicite:8]{index=8}

Groups 3 & 4 — station and sea-level pressure

3PPPP — station pressure in tenths of hPa (encode thousands as required); 4PPPP — mean sea level pressure. See Pressure section. :contentReference[oaicite:9]{index=9}

Group 5 — pressure tendency (5appp)

Indicator a describes the character of pressure change (rising, falling, steady, etc.) and ppp gives amount of change in tenths of hPa over the past 3 hours. Table below. :contentReference[oaicite:10]{index=10}

Group 6 — precipitation (6RRRtR)

RRR is the precipitation amount (mm) over the period indicated by tR (e.g. 1=1h, 6=6h). See precipitation table below. :contentReference[oaicite:11]{index=11}

Group 7 — present & past weather (7wwW1W2)

ww = present weather code (table 4678); W1 and W2 = past weather codes. These tables are large and authoritative — the WMO registry is the canonical source (we include a practical subset below and link to WMO full registry). :contentReference[oaicite:12]{index=12}

Group 8 — cloud types & amounts (8NhCLCMCH)

Nh — amount of low cloud (or medium if none). CL/CM/CH give cloud genera/type codes for low/medium/high levels. Table below. :contentReference[oaicite:13]{index=13}

Group 9 — actual minute (9GGgg)

Used when actual observation minute differs more than the allowed threshold from nominal hour (GGgg = hhmm). Optional. :contentReference[oaicite:14]{index=14}

Cloud amount (N) & cloud types (CL, CM, CH)

Cloud amount digits (N) follow WMO table for oktas — the digit encodes the fraction of the sky covered by cloud. If no low cloud (CL) exists the Nh reports amount of medium cloud (CM).

CodeCloud type / genus (example)
0No significant low cloud (or none)
1Cumulus (Cu) — small cumulus fragments

Pressure groups (3PPP, 4PPPP, 5appp)

3PPPP — station pressure in tenths of hPa (encoded so that the last three digits present the pressure value; the thousands digit may be implicit). 4PPPP — mean sea level pressure encoded similarly. 5appp — pressure tendency: a is the characteristic (coded 0–8), ppp is pressure change in tenths of hPa over prior 3 hours. See the tendency table below.

a (tendency code)Description (common)
0Increasing, then decreasing (net small change)
1Increasing steadily
2Increasing, then steady
3Increasing, then increasing faster
4Decreasing, then increasing
5Decreasing, then steady
6Decreasing, then decreasing faster
7Steady
8Unclassified / variable

The exact textual descriptions and mapping are in the WMO Manual on Codes; use those descriptions for operational reporting. :contentReference[oaicite:20]{index=20}

Precipitation — group 6RRR tR

RRR = precipitation amount in mm (coded); tR indicates the period (e.g. 1 = 1 hour, 6 = 6 hours, 24 = 24 hours — coding limited by 1 digit options; consult message examples for local practice). Below are common tR codes.

tRPeriod / comment
01 hour
110 minutes (sensor-specific)
33 hours
66 hours (very common)
924 hours

Many modern stations and NMHS adopt fixed intervals (6-hour totals etc.). WMO guidance explains exact coding conventions. :contentReference[oaicite:21]{index=21}

Wind (dd ff) and wind indicator (i_w)

dd — true wind direction in tens of degrees (00 = calm / variable depending on coding convention). ff — wind speed coded per units indicated by i_w. i_w specifies whether speed is in m/s, knots, or coded differently for automatic sensors; it also indicates if gusts are included as separate groups. See the i_w mapping in official SYNOP tables. :contentReference[oaicite:22]{index=22}

i_wMeaning (example)
0Wind observed, speed in knots
1Wind observed, speed in m/s
3Wind observed, speed in tenth metres/sec (sensor-specific)
8Calm (no wind)

Exact i_w codes and their units are in WMO FM-12. If using automatic sensors consult manufacturer mapping to SYNOP codes. :contentReference[oaicite:23]{index=23}

Automatic vs staffed stations & missing data

Automatic observing systems can measure many elements but cannot always determine some human-interpreted items (e.g. present weather types at low intensity, or cloud genus). Such stations will either omit those groups or use special codes (slashes) to indicate not observed. The ix indicator helps decoders know whether a station is automatic or manned and whether standard past-weather groups are present. :contentReference[oaicite:24]{index=24}

Missing data convention: slashes (e.g. /////) are used for unavailable numeric groups; check the WMO manual for the correct slash placement per group.

Worked examples (typical decodings)

Example 1 (simple):
01124 72503 12566 63015 10106 20050 30003 40016 53048 60071 91151
  • 01 12 — day 01, 12 UTC.
  • 4 — wind indicator (see i_w).
  • 72503 — station id.
  • 63015 — cloud cover 6/8, wind direction ≈300°, wind speed 15 kt.
  • 10106 — air T = 10.6 °C.
  • 20050 — dew point = 5.0 °C.
  • 30003 — station pressure 1000.3 hPa.
  • 40016 — MSLP 1001.6 hPa.
  • 53048 — pressure tendency coded, net change +4.8 hPa (see 5appp table).
  • 60071 — 7.1 mm precipitation in past 6 h.
  • 91151 — actual time 11:51 UTC (GGgg).
Example 2 (present weather):
20183 13012 60015 71004 70020 12345 70103 7 45 102 003

(This is an illustrative string — ensure your message format follows the FM-12 ordering). Use the ww table above to decode present weather groups such as heavy rain, fog, or thunderstorms.

For more worked examples and local practice datasets consult your NMHS training materials or the WMO observing handbooks. :contentReference[oaicite:25]{index=25}
